# Phase 3: Multi-Sample UCM Analysis

## Overview

This analysis examines the **internal variability** of VLA predictions
by running GR00T N1.6 K times per observation with different random seeds.

**Key difference from Phase 1**:
- Phase 1: Structure of VLA-Expert *error* across timesteps
- Phase 3: Structure of VLA *internal variability* at each timestep

**Data**: 50 episodes, 669 timesteps, K=30 samples each
