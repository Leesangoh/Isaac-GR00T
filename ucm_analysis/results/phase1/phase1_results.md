# Phase 1: UCM Decomposition of VLA-Expert Error

## Overview

This analysis decomposes VLA (GR00T N1.6) prediction errors against expert actions
from BridgeData V2 using the Uncontrolled Manifold (UCM) framework.

**Key question**: Is VLA error concentrated in task-irrelevant dimensions (UCM hypothesis)?

- UCM ratio > 1: Error concentrated in task-irrelevant space (supports hypothesis)
- UCM ratio = 1: Error uniformly distributed (null hypothesis)
- UCM ratio < 1: Error concentrated in task-relevant space (opposes hypothesis)
